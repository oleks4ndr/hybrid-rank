# Hybrid Rank - Hybrid Retrival Pipeline

### Oleksandr

## Implemented So Far

- script and logic to download wands dataset (products, queries, judgements)
- script and logic to verify data

## Usage

1. Make Python Virtual Environment

   `make venv`

2. Activate

   `source .venv/bin/activate`

3. Download & verify data

   `python scripts/download_data.py wands`

   `python scripts/verify_data.py wands`
